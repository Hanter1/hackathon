# Установка и запуск (Easy People)

## 1. Требования

- PHP 7.4+ с расширениями: PDO, PDO_SQLite, session, mbstring
- Веб-сервер (Apache/Nginx) с document root в корне проекта

## 2. Установка на сервер

1. Загрузите файлы проекта в корень сайта (например `public_html`).

2. **Однократная установка БД и админки:** откройте в браузере:
   ```
   https://ваш-домен.by/install/install.php
   ```
   Будут созданы таблицы и учётная запись администратора.

3. **Вход в админку:**
   - URL: `https://ваш-домен.by/admin/`
   - Логин: **admin**
   - Пароль: **admin123**
   Сразу смените пароль (через БД или добавьте смену пароля в админке).

4. После установки **удалите папку `install/`** или переименуйте `install.php`, чтобы нельзя было пересоздать БД.

## 3. Структура

| Раздел        | Список (фронт)     | Одна запись (фронт)     | Админка              |
|---------------|--------------------|-------------------------|----------------------|
| Преподаватели | `/members/`        | `/members/profile.php?slug=xxx` | `/admin/teachers.php` |
| Курсы         | `/courses.php`     | `/course.php?slug=xxx`  | `/admin/courses.php` |
| События       | `/events.php`      | `/event.php?slug=xxx`   | `/admin/events.php`  |
| Блог          | `/blog.php`        | `/post.php?slug=xxx`    | `/admin/blog.php`    |

### Смена пароля администратора

В админке: **Пароль** в меню → форма смены пароля (текущий, новый, подтверждение).

### Главная страница

В корне есть **index.php** — динамическая главная с блоками «Курсы», «События», «Новости» из БД. Чтобы сервер открывал её по умолчанию, настройте `DirectoryIndex index.php index.html` или переименуйте статичный `index.html` в `home.html`.

По умолчанию используется **SQLite**: файл `data/site.db` (создаётся при первом запуске `install/install.php`). Папка `data/` должна быть доступна на запись для веб-сервера.

### Использование MySQL

Откройте `config/db.php`, закомментируйте блок с SQLite и раскомментируйте блок с MySQL, укажите хост, имя БД, логин и пароль. Таблицы создаются тем же скриптом `install/install.php` (для MySQL может потребоваться правка SQL в `install/install.php` под синтаксис MySQL).

## 4. Безопасность

- Не коммитьте в git файл `.vscode/sftp.json` (пароль FTP) — он добавлен в `.gitignore`.
- После установки удалите или ограничьте доступ к папке `install/`.
- Рекомендуется сменить пароль администратора после первого входа.
